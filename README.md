### 主题前言

这里是 L-Siren，我自己在用的 WordPress 主题。

项目继承自 [后宫学长的 H-Siren](https://github.com/galnetwen/H-Siren)，经过作者同意，在这里继续维护。再往前是 [蜜汁路易](https://www.cssplus.org/) 修改的 Siren，以及 [Fuzzz](http://fui.im/) 的 Akina。感谢几位作者之前的工作。

这个主题用了好几年，期间自己也塞了不少功能。以前能跑就放着，现在准备把这些东西整理一下，修掉旧问题，之后继续在这个仓库开发。

目前先整理已经在用的功能。WordPress 7 的完整迁移还没有做完。

### 主题修改

- 访客评论增加邮箱验证码，6 位数字，已登录用户不用填。在“文章页”里可以关闭，按钮和输入框也一起调整了，不再挤着“发送评论”
- 验证码后端拆到 `inc/captcha.php`，改用参数化查询，处理重复发送、尝试次数和验证码用完后继续提交的问题；注册页的算术验证也在这里
- MathJax 支持 PJAX 切页、评论翻页和追加内容。旧公式离开页面时清理记录，浏览器前进、后退时从原公式重新排版；整页切换后重新编号，追加评论时继续编号，不再因为旧标签报错
- 首页背景视频支持 HLS（m3u8），也保留 MP4。旧的“MV”写法仍然会补上 `.mp4`，换源时释放旧播放器，加载失败可以重新点击
- `iplib2` 重新整理了 APNIC 数据处理，IPv4、IPv6 都查本地范围，不用再手工给 IPv6 加方括号。可以在后台手动更新，也保留 SSH 脚本
- 增加“L-Siren 运维仪表板”，入口在顶部工具栏和“外观”菜单。管理员可以更新 IP 库、测试 IP、初始化验证码表，下载时可以填写仅本次使用的代理
- 修正主题设置里单选框的圆点和排列，样式只作用于主题设置页
- 运维仪表板的“第一屏”可以配置移动云盘视频，Auth 和 Cookie 只留在后台。前台使用固定播放入口，缓存过期后按需获取新的预览链接，再跳转到云盘播放
- 修复 WordPress 7 下编辑器样式没有正常加载的问题。编辑区域改用独立 CSS，不再直接加载整份前台样式
- 私密评论补上 REST 接口的正文遮蔽；关闭私密评论开关后，已有评论仍保留私密状态
- 打赏页沿用原主题的月份归档样式，按年月倒序展开记录，匿名记录显示“未留名”，名单不展示金额
- 整理 APlayer 的歌单加载，修正接口字段与播放器字段的对应关系，设置请求超时，补上空歌单和加载失败提示

首页的“视频地址”和“视频名称”合成一个“视频列表”，每行填写一个完整地址，MP4、m3u8 和本站视频 API 可以混用，继续随机播放和换片。移动云盘的授权和允许更新的文件在运维仪表板的“第一屏”配置，复制固定播放地址到首页列表即可；列表以外的文件不能获取或更新预览链接。

云盘的缓存保存播放链接和有效期，视频文件仍由云盘直接传输。访客播放时，如果缓存已经到期，后台再去获取新的地址；没有播放请求时不运行。原样保存配置、增删其他视频或调整名单顺序，都不会清掉仍然有效的链接。更换 Auth、Cookie、接口服务器或检查间隔时，相关缓存才会失效；管理员也可以单独点击“更新链接”。

邮箱验证码通过 WordPress 的 `wp_mail()` 发邮件。新站使用前，在运维仪表板的“文章页”里初始化验证码表，再配置邮件服务。已有表不会被清空或修改。

MathJax 脚本仍由插件或其他方式加载，主题按 MathJax 3 的接口处理，本站目前使用 3.2.0。开启 PJAX 时需要全站加载脚本，否则从普通页面跳进公式文章时可能没有 MathJax 可用。关闭 PJAX 不影响正常排版和评论 AJAX。

仓库不带 APNIC 原始数据和生成的地址库。首次使用在运维仪表板里点击“更新 IP 库”，或者运行 `iplib2/get_latest.sh`。后台由 PHP 独立处理，SSH 继续用 C++，具体见 [iplib2 的说明](iplib2/README.md)。

打赏记录仍从原站带 WordPress 表前缀的 `reward` 表读取。

音乐播放器的接口地址和歌单 ID 仍写在 `playlist.js`，暂时保留本站配置。含账号 Cookie 的 `meting/api.php` 不放进仓库，音乐接口需要单独准备。

### 功能介绍

**背景图API**

网页背景图、文章列表、文章顶部特色图，均支持随机图片API，并使用 MD5 8 位随机数载入，大几率减少重复图片的现象；

**网页背景图显示顺序：**  
默认显示主题自带随机图，如果填写“背景图API”将显示“背景图API”的随机图。

**文章列表、文章或者页面的顶部图片显示顺序：**  
优先显示编辑文章时所设定的特色图，没有设置特色图的情况下的逻辑和上一条一样。

**注意：**  
不支持调用动态 URL 的随机图 API ，仅支持伪静态 URL ，因为本主题会在 URL 结尾添加动态随机数以防止随机图重复。
